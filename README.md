# 蒼井音呼 — 第3案「街歩きの小径」

指定の `aoiinko_3` Gitフォルダーに制作した独立した比較用サイトです。

## デザイン

FVの水彩風景から細い小径が続き、木陰、黄色い花、街角、開けた空へ移ります。前景の草花・動物と遠景は異なる速さで動き、章ごとに背景色が変化。白い柴犬や青いインコを道沿いの小さな発見として配置しています。

本文は18px、スマートフォンは16pxを基本に、景色の余白へまとめています。原稿は現在の短縮版。経歴は5項目の開閉式です。街角の絵は特定の実在場所を記録したものではなく、オリジナルの世界観イラストです。

## プレビュー

このフォルダーで `node serve.mjs` を実行し、http://127.0.0.1:4175/ を開きます。追加パッケージ・ビルドは不要です。他案とは異なるポートを使用。

- `index.html`: 本文、5つの章、SEO・共有情報
- `styles.css`: 小径・風景・余白・レスポンシブ
- `script.js`: 小径の描画、視差、背景色、目次、表示演出
- `site-config.js`: 後日追加する連絡先と作品
- `assets/scenes/`: この案専用に生成した水彩風景
- `ASSET-PROMPTS.md`: 組み込みImagegenで実行したプロンプト

`script.js` または `site-config.js` の変更後は `node sync-site.mjs` でHTML内のインライン版を更新してください。

## 連絡先・掲載誌

連絡先は未提供のため準備中の案内を表示しています。`site-config.js` の `contactUrl` にHTTPSフォームURLまたは `mailto:メールアドレス` を設定すると、ボタンのリンク先になります。

掲載誌写真と俳句原文は未提供。`publications` に `image`, `alt`, `title`, 任意の `caption`, `haiku`, `vertical` を追加するとギャラリーが表示されます。`vertical: true` で縦書きになります。

## 操作と動き

ブラウザーの通常スクロールを使用。メニューと道しるべから各章へ移動できます。経歴は標準details要素でキーボードにも対応。「動きを止める」またはOSのモーション抑制で視差・フェードを省略。JavaScriptが無効でも本文とメニュー、経歴を利用できます。
